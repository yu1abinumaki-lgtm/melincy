# Melincy - фиолетовое портфолио на Nuxt

Полностью новая версия сайта Евгения Трофимовича. Nuxt 4.6.4, Vue 3.5.45, TypeScript 5.9.3, HTML-шаблоны Vue, собственный CSS и JavaScript в браузере. Предыдущая версия сохранена отдельно в `melincy-portfolio`.

## Быстро посмотреть готовый сайт

В архив включена проверенная статическая сборка `.output/public`. Для её просмотра достаточно установленного Node.js, установка зависимостей не нужна.

В Windows запустите `start-preview.cmd` двойным щелчком, затем откройте:

**http://127.0.0.1:4174**

Или выполните из папки проекта:

```powershell
npm run serve
```

Остановка сервера: Ctrl+C. Файл `index.html` внутри сборки нужно открывать через HTTP-сервер, а не двойным щелчком: Nuxt использует модули и абсолютные пути к ресурсам.

## Разработка

Требуется Node.js 22.22.3+ в ветке 22, 24.15.0+ в ветке 24 или 26+. Здесь проект собран на Node.js 22.23.4.

```powershell
npm ci
npm run dev
```

Сервер разработки по умолчанию открывается на `http://127.0.0.1:3000`. Точный адрес выводится в терминале. Изменения Vue и CSS отображаются автоматически.

Проверка и сборка:

```powershell
npm run typecheck
npm run generate
```

`npm run build` также доступен для серверной сборки Nuxt. Для этого портфолио достаточно статической генерации. На статический хостинг загружается содержимое `.output/public`.

## Что менять

Имя, Telegram, описание и список проектов редактируются в `app/data/portfolio.ts`. Контактные ссылки формируются из этих же данных, не нужно менять их в нескольких компонентах.

Палитра задаётся в начале `app/assets/css/main.css`. Декоративные оттенки также используются в `HeroVisual.vue`. Отступы используют шаг 8 px.

Раздел навыков сейчас честно описывает **стек самого сайта**. Он не выдаётся за подтверждённый список личных компетенций. После уточнения своего стека можно заменить данные и подпись в `SkillsSection.vue`.

## Добавление проекта

1. Положите обложку в `public/projects/`, создав папку при необходимости.
2. Добавьте объект в массив `projects` в `app/data/portfolio.ts`.
3. Для нового опубликованного состояния снова выполните `npm run generate`.

```typescript
export const projects: Project[] = [
  {
    id: 'my-first-project',
    title: 'Название реального проекта',
    category: 'Веб-приложение',
    description: 'Краткое описание задачи и продукта.',
    cover: '/projects/cover.webp',
    coverAlt: 'Что изображено на обложке',
    tools: ['Nuxt', 'TypeScript'],
    details: [
      { title: 'Задача', text: 'Реальная задача проекта.' },
      { title: 'Решение', text: 'Ваша роль и выполненная работа.' },
      { title: 'Результат', text: 'Фактический результат.' }
    ],
    links: []
  }
]
```

Для настоящих ссылок используется формат `{ label: 'Открыть проект', url: 'ВАШ_HTTPS_АДРЕС' }`. Без настоящей ссылки оставьте пустой массив. После добавления работ пустой блок автоматически заменится сеткой. Нажатие карточки открывает подробности.

## Дизайн и удобство

- Тёмный фон, фиолетовый акцент, мягкий неон на орбитах и декоративных областях.
- Основной текст без свечения и градиентов, со светлым цветом и свободным межстрочным интервалом.
- Локальный шрифт Onest с кириллицей. Нет запросов к Google Fonts и внешних UI-библиотек.
- Кнопка «Неон» отключает декоративную подсветку и сохраняет выбор в браузере.
- Плавная прокрутка, спокойная анимация, поддержка `prefers-reduced-motion`.
- Доступные имена кнопок, видимый фокус, ссылка пропуска навигации, нативное модальное окно.
- Реальные данные Melincy и `@melincy_dev`. Почта и GitHub не придуманы. Пример проекта явно подписан.

## Выполненная проверка

- `npm run typecheck` прошёл.
- `npm run generate` прошёл, страница предрендерена в HTML.
- Локальная сборка отвечает HTTP 200.
- Проверены ширины 320, 390, 768, 1024 и 1440 px. Горизонтального переполнения не обнаружено.
- Визуально просмотрены компьютер, телефон, планшет и полная страница.
- Проверены мобильное меню и закрытие после перехода, открытие подробностей, Escape, возврат фокуса, блокировка прокрутки под окном.
- Проверены копирование Telegram и сохранение настройки неона после перезагрузки.
- В консоли браузера нет ошибок и предупреждений.

Nuxt при сборке на Windows вывел предупреждение о `cache-driver.mjs`; генерация всех страниц завершилась успешно. `npm audit` выявил 6 low и 6 moderate предупреждений в цепочках зависимостей инструментов сборки, high/critical нет. Готовая статическая версия не запускает эти Node.js-пакеты на хостинге. Обновление зависимостей можно планировать отдельно; принудительное понижение Nuxt через `npm audit fix --force` не применялось.

## Публикация

Готовая версия сохранена локально. Онлайн-публикация через Sites не выполнена: при регистрации этого портфолио сервис сообщил, что Sites Git пока недоступен для клиента. Содержимое `.output/public` можно разместить на любом обычном статическом хостинге.
